Privacy Policy — luxwave Publisher

Last updated: 2026-10-08

luxwave Publisher ("the app") is a private, single-user tool operated by the owner of the LUXWAVE YouTube channel. It is not offered to the public.

What the app accesses

Through Google OAuth, the app requests these YouTube Data API scopes, only for the channel owner's own account:

  • youtube.upload — to upload the channel's own finished videos.
  • youtube.force-ssl — to set thumbnails and update titles, descriptions, tags, chapters, privacy status and playlists of the channel's own videos.
  • youtube.readonly — to read the channel's own video list and processing status to confirm uploads.

How data is used and stored

  • The app does not access, collect or store data about any other YouTube user.
  • The OAuth token is stored only on the channel owner's local computer and is never shared or transmitted to any third party.
  • No data is sold, used for advertising, or used to train AI models.
  • The app never deletes content automatically.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account permissions (also https://security.google.com/settings/security/permissions). The only data the app keeps is the OAuth token on the owner's computer; when access is revoked or the tool is no longer used, the token file is deleted. The app does not keep any copies of YouTube API data beyond what is needed to confirm an upload, and none older than 30 days.
